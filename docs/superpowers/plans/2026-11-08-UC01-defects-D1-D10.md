## Review Focus

1. **CSRF/Origin validation bypass** — Cross-site requests must fail with proper CSRF protection or SameSite+Origin/Referer validation. Test: POST /api/auth/login from different origin should return 403.
2. **Refresh token reuse detection** — Reuse of revoked refresh token must revoke entire token family and log security event. Test: use old refresh token after rotation → all tokens invalidated.
3. **User enumeration via error messages** — Register/login errors must not reveal whether email exists. Test: register with existing email → same generic error as non-existing.
4. **Login brute force** — Rate limiting must block after N failed attempts. Test: 5+ failed logins → 429 Too Many Requests with retry-after.
5. **JWT secret leakage** — No default secret in versioned config; secret only from env var. Test: startup without JWT_SECRET env var → fail fast.

```java
    if (jwtSecret == null || jwtSecret.isBlank()) {
        throw new IllegalStateException(
            "JWT secret not configured. Set 'jwt.secret' environment variable (JWT_SECRET). "
            + "Must be at least 256 bits (32 chars) for HS256."
        );
    }
    if (jwtSecret.getBytes(StandardCharsets.UTF_8).length < 32) {
        throw new IllegalStateException(
            "JWT secret must be at least 256 bits (32 characters). "
            + "Current length: " + jwtSecret.getBytes(StandardCharsets.UTF_8).length + " bytes."
        );
    }
    this.secretKey = Keys.hmacShaKeyFor(jwtSecret.getBytes(StandardCharsets.UTF_8));
}
```
